# Lissajous Curves – C# Implementation

This project visualizes **Lissajous curves**, a family of complex harmonic motion figures generated by combining two perpendicular sinusoidal oscillations.

## 🧮 Description

A Lissajous curve is defined by the parametric equations:

**x(t) = A · sin(a·t + δ)**  
**y(t) = B · sin(b·t)**

where:

- **A**, **B** → amplitudes  
- **a**, **b** → angular frequencies  
- **δ** → phase difference  

This program allows you to **experiment with different parameters** and observe how they affect the resulting shape.

For more information, you can check this [wiki page](https://en.wikipedia.org/wiki/Lissajous_curve).
